## 关键设计决策

### 1. 为什么用 gob 而不是 protobuf？

- Go 原生支持，无需额外依赖
- 序列化和反序列化简单
- 性能足够（小规模索引）

### 2. 压缩时机

- **快照**：总是压缩（gzip）
- **WAL**：可选压缩（默认不压缩，减少 CPU）

### 3. 去重策略

- 使用 SHA1 计算文件指纹
- 检测重复快照，自动清理

### 4. 崩溃恢复

```
启动时：
1. 加载最新的 manifest
2. 加载对应的 snapshot
3. 重放 snapshot 之后的 WAL 操作
4. 完成恢复
```
