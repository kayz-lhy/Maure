# Maure 笔记索引

## 项目结构

```
docs/notes/
├── .obsidian/          # Obsidian 配置
│   ├── app.json         # 应用设置
│   ├── workspace.json   # 工作区设置
│   └── templates/       # 模板
│       ├── task.md      # 任务模板
│       ├── iteration.md  # 迭代模板
│       ├── learning.md  # 学习笔记模板
│       └── weekly.md    # 周报模板
├── iterations/         # 迭代记录
├── learnings/          # 学习笔记
├── tasks/              # 任务笔记
└── weekly/             # 周报
```

## 使用指南

### 创建新任务
1. 打开 Obsidian
2. 使用命令面板 (`Ctrl/Cmd + P`)
3. 输入 "Templater: Create new note from task template"

### 创建新迭代
1. 使用 "Templater: Create new note from iteration template"

### 创建周报
1. 使用 "Templater: Create new note from weekly template"
