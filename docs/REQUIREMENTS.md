# Maure 需求规格说明书

## 1. 项目概述

**项目目标**：构建一个轻量级搜索引擎，适合学习、研究和小规模应用。

**核心原则**：
- 简单优先
- 代码可读
- 易于理解
- 资源占用低

---

## 2. MVP 功能需求

### P0 - 必须实现

| 编号 | 功能 | 描述 |
|------|------|------|
| F-ADD-01 | 文档添加 | 创建文档并添加到索引 |
| F-ANA-01 | 标准分词 | 英文分词、 lowercase |
| F-IDX-01 | 倒排索引 | 术语到文档的映射 |
| F-QRY-01 | 词项查询 | 精确词项匹配 |
| F-QRY-02 | 布尔查询 | AND/OR/NOT 组合 |
| F-QRY-03 | 短语查询 | 连续词项匹配 |
| F-SCR-01 | TF-IDF 评分 | 经典评分算法 |
| F-SCR-02 | BM25 评分 | 现代评分算法 |
| F-STR-01 | 内存索引 | RAM 中存储索引 |
| F-STR-02 | 文件持久化 | 索引写入磁盘 |

### P1 - 应该实现

| 编号 | 功能 | 描述 |
|------|------|------|
| F-DEL-01 | 文档删除 | 从索引中删除文档 |
| F-UPD-01 | 文档更新 | 删除后重新添加 |
| F-QRY-04 | 范围查询 | 数值/日期范围 |
| F-QRY-05 | 模糊查询 | 编辑距离匹配 |

### P2 - 期望实现

| 编号 | 功能 | 描述 |
|------|------|------|
| F-QRY-06 | 通配符查询 | * 和 ? 通配符 |
| F-MRG-01 | 段合并 | 合并小段为大段 |
| F-HIG-01 | 结果高亮 | 匹配词高亮 |
| F-CLI-01 | CLI 工具 | 命令行交互 |

## 3. 非功能需求

### 性能需求

| 编号 | 需求 | 目标 |
|------|------|------|
| N-PERF-01 | 10万文档索引 | < 30秒 |
| N-PERF-02 | 查询延迟 | < 100ms |
| N-PERF-03 | 内存占用 | < 500MB |

### 质量需求

| 编号 | 需求 | 目标 |
|------|------|------|
| N-QUAL-01 | 测试覆盖率 | > 50% |
| N-QUAL-02 | 代码规范 | go vet 通过 |
| N-QUAL-03 | 文档完整 | 核心 API 有注释 |

---

## 4. CLI 需求

### 命令列表

| 命令 | 功能 |
|------|------|
| `maure init` | 初始化索引 |
| `maure add <file>` | 添加文档 |
| `maure search <query>` | 搜索 |
| `maure info` | 查看索引状态 |
| `maure optimize` | 优化索引 |
