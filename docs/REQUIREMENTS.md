# Maure 需求规格说明书

## 1. 项目目标

构建一个轻量、可部署、可嵌入的搜索引擎，主要面向：

1. 日志检索与排障（日志分析场景）
2. 中小规模站内检索
3. 搜索引擎原理学习与实验

## 2. 功能需求

### P0（核心能力）

| 编号 | 功能 | 描述 |
|------|------|------|
| F-ADD-01 | 文档写入 | 添加文档并建立索引 |
| F-DEL-01 | 文档删除 | 删除文档并同步倒排 |
| F-ANA-01 | 标准分词 | Standard Analyzer |
| F-IDX-01 | 倒排索引 | 术语到文档映射 |
| F-QRY-01 | 词项查询 | 精确词项匹配 |
| F-QRY-02 | 布尔查询 | AND/OR/NOT |
| F-QRY-03 | 短语查询 | 顺序词项匹配 |
| F-SCR-01 | BM25/TF-IDF | 基础相关性评分 |
| F-STR-01 | 文件持久化 | Snapshot + WAL |
| F-CLI-01 | CLI 工具 | 命令行操作 |
| F-API-01 | HTTP API | 提供搜索与文档接口 |

### P1（增强能力）

| 编号 | 功能 | 描述 |
|------|------|------|
| F-LOG-01 | 日志解析导入 | JSON/Logback/auto |
| F-AGG-01 | 聚合统计 | count/group |
| F-HLT-01 | 高亮片段 | 返回命中片段 |
| F-COMP-01 | 命令兼容 | 历史 CLI 写法兼容过渡 |

### P2（后续规划）

| 编号 | 功能 | 描述 |
|------|------|------|
| F-QRY-04 | 范围查询 | 数值/日期范围 |
| F-QRY-05 | 模糊查询 | 编辑距离 |
| F-QRY-06 | 通配符查询 | `*` / `?` |
| F-SEC-01 | 鉴权与租户隔离 | 服务化部署能力 |

## 3. 非功能需求

### 性能目标（阶段性）

| 编号 | 需求 | 目标 |
|------|------|------|
| N-PERF-01 | 中等规模索引加载 | 可在可接受时间内启动 |
| N-PERF-02 | 常见查询延迟 | 日志场景可交互 |
| N-PERF-03 | 资源占用 | 单机可部署 |

说明：当前已进入“先确保正确性，再做系统化性能优化”的阶段，优化路线见 `docs/reports/search-api-performance-analysis.md`。

### 质量目标

| 编号 | 需求 | 目标 |
|------|------|------|
| N-QUAL-01 | 自动化测试 | 核心路径有单测与集成测试 |
| N-QUAL-02 | 代码检查 | `go vet` 通过 |
| N-QUAL-03 | 文档同步 | 对外命令/API 与实现一致 |

## 4. CLI 需求（当前）

### 核心命令

| 命令 | 功能 |
|------|------|
| `maure init <path>` | 初始化索引 |
| `maure add <file>` | 添加文档 |
| `maure parse-log <file>` | 解析日志并导入 |
| `maure search <query>` | 搜索 |
| `maure stats` | 查看索引统计 |
| `maure compact` | 触发快照提交 |
| `maure serve` | 启动 HTTP 服务 |

### 兼容要求

1. 旧参数顺序在兼容窗口内继续可用。
2. 旧写法需给出 deprecate 提示。
3. 推荐写法在帮助文档中优先展示。
